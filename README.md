# Software Developer Portfolio

A responsive single page portfolio focused on project work, workflow previews, and engineering decisions.

## Projects

* Kiyudin, a desktop application for legal practice workflows, using C# and SQL.
* Chavruta Live Bot, a Telegram bot for Torah study groups, with lesson flows, reminders, recordings, and activity logs.
* Zero Knowledge Windows Backup, a Windows application with local encryption, deduplication, resumable uploads, and restore points.
* Crypto Trading and Risk Bot, a Python project overview for trading automation and risk management.

## Contact form

The site includes a custom contact form interface. Email delivery is currently disabled because no Web3Forms key is configured. No recipient email or service key is stored in this repository.

## Technology

HTML, Tailwind CSS via CDN, and vanilla JavaScript. The site is served directly from `index.html` and needs no build step.
