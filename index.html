Zero Knowledge Windows Backup

↗

Problem

Backups need to protect file contents and structure while still supporting recovery of earlier versions.

Implementation

A .NET 8 WPF app chunks and encrypts data locally, deduplicates repeated content, and supports point in time restore.

ENGINEERING CHALLENGE

Keep file I/O, encryption, and upload work independent. The pipeline is resumable, retries rate limited transfers, and allows restoring a chosen snapshot.
